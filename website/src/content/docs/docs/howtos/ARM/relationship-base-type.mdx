:::caution
The Relationship base type is **experimental**. Its shape may change in future versions of the
`@azure-tools/typespec-azure-resource-manager` library. Applying `@azureBaseType` (directly or
through the `Relationship` template) in a provider namespace emits the `basetypes-experimental`
warning, which you must explicitly suppress while the feature is experimental.
:::

A _Relationship_ is an ARM base type: a structured contract that links a source scope to a target
entity. The library provides the `Relationship` extension-resource template together with the
`RelationshipProperties` model that carries the required source and target descriptors. These live
in the `Azure.ResourceManager.BaseTypes.Relationships` namespace.

```typespec
using Azure.ResourceManager.BaseTypes.Relationships;
```

## Required relationship properties

Every relationship resource must expose the `RelationshipProperties` schema. Derive your property
bag from it — enforced by the
[`use-relationship-required-properties`](/docs/libraries/azure-resource-manager/rules/use-relationship-required-properties)
rule — and add your own resource-provider-specific fields. `RelationshipProperties` supplies:

- `baseTypes` — ARM-managed base type descriptors (read-only).
- `sourceId` / `sourceTenant` — the relationship source identifier and its tenant.
- `targetId` / `targetTenant` — the relationship target identifier and its tenant.
- `provisioningState` — the provisioning state (read-only).

`RelationshipProperties<ProvisioningState>` takes an optional provisioning-state parameter, letting
you supply a custom LRO status union:

```typespec
/** Provisioning state values for a Contoso dependency relationship async flow. */
@Azure.Core.lroStatus
union DependencyOfProvisioningState {
  ResourceProvisioningState,
  Accepted: "Accepted",
  Provisioning: "Provisioning",
  Deleting: "Deleting",
  string,
}

/** Properties for a Contoso dependency relationship. */
model DependencyOfProperties
  is RelationshipProperties<ProvisioningState = DependencyOfProvisioningState> {
  /** Metadata describing the relationship source and target types. */
  metadata: DependencyOfMetadata;
}
```

## Defining the relationship resource

The `Relationship<Properties>` template creates an ARM `ExtensionResource` and automatically applies
the `@azureBaseType` decorator for the Relationship base type. Add the usual `ResourceNameParameter`
spread and suppress the experimental warning:

```typespec
#suppress "@azure-tools/typespec-azure-resource-manager/basetypes-experimental" "Experimental BaseTypes"
model DependencyOf is Relationship<DependencyOfProperties> {
  ...ResourceNameParameter<
    Resource = DependencyOf,
    KeyName = "relationshipName",
    SegmentName = "dependencyOf",
    NamePattern = "^[a-zA-Z0-9_.-]{1,64}$"
  >;
}
```

Because a relationship is an extension resource, its operations are defined over a scope using the
`Extension.*` operation templates. The interface below routes at
`{scope}/providers/Microsoft.ContosoRelationships/dependencyOf/{relationshipName}`:

```typespec
/** Defines dependency relationship operations for a source scope. */
interface DependencyOfOps<Scope extends Azure.ResourceManager.Foundations.SimpleResource> {
  get is Extension.Read<Scope, DependencyOf>;
  create is Extension.CreateOrReplaceAsync<Scope, DependencyOf>;
  update is Extension.CustomPatchAsync<
    Scope,
    DependencyOf,
    Azure.ResourceManager.Foundations.ResourceUpdateModel<DependencyOf, DependencyOfProperties>
  >;
  delete is Extension.DeleteWithoutOkAsync<Scope, DependencyOf>;
  list is Extension.ListByTarget<Scope, DependencyOf>;
}

/** Operations over any source scope. */
@armResourceOperations
interface DependencyOfRelationships extends DependencyOfOps<Extension.ScopeParameter> {}
```
